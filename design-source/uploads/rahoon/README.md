# رهون — logo artwork and usage

The Arabic name is **رهون**. In every approved logo it uses that exact spelling and natural joins. The final SVG artwork is outlined, so it renders consistently without installing a font.

## Explored concepts

| Concept | Visual idea |
| --- | --- |
| 01 — Resolution path | A bounded, open shape traces a route to a small orange end point. |
| 02 — Aligned stages | Several parallel starts resolve into an orderly common progression. It represents how separate parties and case stages are coordinated, without prescribing a single outcome. **Selected direction.** |
| 03 — Common ground | Two open sides meet through a modest central bridge, suggesting coordination and agreement. |

## Placement and scale

- Clear space **X** is one quarter of the visible symbol's height. Leave at least X beyond the outermost artwork on every side of the complete logo. The SVG viewBox padding is not a substitute for this clear space.
- Horizontal logo: minimum **170 CSS px wide**. Stacked logo: minimum **100 CSS px wide**.
- Transparent symbol: minimum **24 CSS px**; icon tile: minimum **48 CSS px**. Use the supplied **32 × 32** favicon for browser tabs.
- Preserve the artwork's aspect ratio. On a dark surface, use the dark version; for one-color printing, use the charcoal or white monochrome version.
